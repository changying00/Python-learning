# Python 开发模式

## 交互式编程

打开命令提示符（WIN + R， 输出 cmd） ,   输入 python  进入 交互式编程环境 

- help 函数 ：  查看某个函数、类、模块 的帮助文档、

```python
# 查看 print 的帮助文档
help(print)
```

- print 函数 ：  输出 多个值 到 控制台(默认) 上
  - args: 如果一个参数的前面有一个 `*` ,  代表 此时 可以传递 0 ~ N 个参数， 且多个参数之间使用逗号分隔
  - sep: 关键字参数 ，  设置 打印的多个数据之间的 分隔符 、默认是 一个空格
  - end: 关键字参数， 当输出完最后一个值的时候， 追加的 字符串，默认值是一个 换行符 ~~~

```python
print(*args, sep=' ', end='\n', file=None, flush=False)
```

**  \* 参数 后面的参数 都是关键字参数 、关键字参数 在调用函数的时候，必须提供关键字调用   **

- input 函数 ：从标准键盘读取内容
  - prompt :  输入 提示词、默认为 空字符串

```python
input(prompt="")
```

**input 函数 返回 从键盘 输入的 文本内容、 如果输入的是数字、可以使用 int / float 函数 转成 整数/浮点数**

# 常见的运算符

- 算术运算符:   + (加法)、 -  (减法) 、 `*`  (乘法) 、 /  (除法) 、 //  （整除求商）、   %  （整除求余）、  `**`  （幂运算）
- 位运算符 :   &  (位与) 、  |  （位或） 、 ^ (异或)  、  ~  （位非）
  
  基于 二进制的运算方式、效率是非常高的。  位运算符 只能 是 整数间的运算 ~~~

|运算符|特点|示例|
|--|--|--|
|&|两个整数的二进制  同位只要有 0 结果为 0， 否则 为 1|3 & 5 = 0011 & 0101 = 0001|
|\||两个整数的二进制  同位只要有 1 结果为 1， 否则 为 0|3 & 5  = 0011 \| 0101  =  0111|
|^|两个整数的二进制  同位不同值 结果为 1， 否则 为 0|3 ^ 5  = 0011 \| 0101  =  0110|
|~|一元运算符、按位取反、0变成 1、 1 变成 0||

- 位移运算符 :   <<  (左移运算符) ,   >> (右移运算符) 
  > 基于 二进制的运算方式 、效率非常高 、位移运算符 只适应于 整数间的运算 
  
  左移运算： 二进制的 低位 补 0 ， 每左移一位、 结果是原来的 2倍
  
  右移运算：  二进制的 高位 正除补 0 ， 负数 补  1 
- 赋值运算符
  > 赋值运算符 是一个语句 、不能作为 表达式使用、 不能再和 其它数据做运算 ~~~
  > 
  > 赋值运算符的优先级 是最低的、 会先计算 赋值运算符 右边表达式的结果 
  ```
  =  
  += 、 -= 、  *=  、 /= 、  //= 、  %=、  **=
  &=  、 |=  、  ^=
  <<= 、 >>=
  ```
- 关系运算符 
  > 关系运算符 可以实现 2个数据之间 的比较 、是一个表达式、且表达式返回的结果一定是一个 bool 类型 ~~~
  > 
  > 主要 为了 判断 和 循环 使用 
  ```
  >  (大于)、 >= (大于等于) 、  <  (小于) 、 <=  (小于等于) 、  == (等于) 、  != (不等于)
  ```
- 逻辑运算符 :   逻辑运算符 主要为了 判断 和循环 使用 
  - 逻辑与  and :    一假即假、 整个表达式的结果 由 exp1 和 exp2 的运算结果 为 最终结果 。
    
    语法：`exp1  and  exp2`  :    当 第一个 表达式 exp1  为 假( 使用 bool函数转后的结果) 的时候 、整个表达式的结果为  exp1 表达式的结果 、当 第一个表达式 为 真 (使用 bool函数转后的结果) ,  那么整个表达式的结果是 exp2 表达式的结果 ~~~ 
  - 逻辑或  or  :    一真即真、整个表达式的结果 由 exp1 和 exp2 的运算结果 为 最终结果 。
    
    语法：`exp1  or  exp2`  :    当 第一个 表达式 exp1  为 真( 使用 bool函数转后的结果) 的时候 、整个表达式的结果为  exp1 表达式的 结果 、当 第一个表达式 为 假 (使用 bool函数转后的结果) ,  那么整个表达式的结果是 exp2 表达式的结果 ~~~
  - 逻辑非  not :   非真即假、 非假即真 
    
    语法：  `not exp`  :  该表达式 返回的结果一定是 bool 类型 、 永远对 exp 表达式计算的结果 取反 ~~~
  
  **逻辑与 and  的优先级  高于 逻辑或 or 。  and  和 or  运算符 都有 短路现象 ~ **
- 海象运算符  `:=`
  >  海象运算符 可以将 赋值语句 转成 表达式 、从而 实现 了 既能 赋值 又能 运算 的效果 ~~~ 
- 三元运算符 
  
  语法 :    `exp1  if condition  else  exp2`    当 condition 这个表达式的值为 True (bool函数转换)， 则 整个三元运算符 表达式 结果 是 
  
  exp1  表达式运算的结果 ， 否则 整个表达式 运算的结果是 exp2 表达式的结果 ~~~  
  
  **三元运算符支持嵌套**
  ```python
  num = input("请输入一个整数")
  
  # 将 键盘输入的内容 转成 整数
  num = int(num)
  
  # 使用 三元运算符 输出 该数字是奇数还是 偶数

  print(ret)
  # 从键盘输入一个字符 S, M 或者 F 、并输出对应的性别
  #  S 代表 保密 、 M 代表 男 F 代表 女
  sex = input("请输入一个字符 S, M 或者 F")
  
  gender = "男" if sex == 'M' else "女" if sex == 'F' else "保密" if sex == 'S' else "未知"
  
  print(gender)
  
  ```
- 成员运算符  in  和 not  in 
  >  成员运算符 主要用于在 可 迭代对象中 ，常见的可迭代对象包含 字符串、列表、元组、集合、字典 等
  > 
  > 成员运算符 是一个表达式 、 返回的结果 是 一个 bool 类型

- 身份运算符  is  和  is  not  
  >  is  / not  is  是用来比较 2个数据的 地址是否一致    a  is  b  等价于   id(a)  == id(b)

# 流程控制

> 判断：  可以通过 某种机制 决定  某些任务 在满足条件的时候 才会触发和执行 。
> 
> 循环：  是计算机用来 解决重复任务的一种非常重要的手段，它可以让某一段任务反复执行，同时也可以和判断结合，更加高效的控制重复的任务 ~~~

## 判断 if 

- 单分支条件判断

```python
if condition:
    pass
```

 condition :  代表 任务执行的条件 、当 条件为真的时候，才会 触发 该条件块中代码的执行 ~

 pass :   是一个关键字 、是一个占位符、用来解决 语法完整问题 ， 如果一个代码块中 暂时不需要写任何代码，可以使用 pass 进行填充 

- 双分支条件判断

```python
if condition:
    pass
else:
    pass
```

如果 conditon 条件不成立 、 会执行 else 块中定义的 代码 

- 多分支条件判断

```python
if condition:
    pass
elif conditon:
    pass
elif conditon:
    pass
....
else:
    pass
```

 elif  结构 可以出现 0 ~ n 个 

**在 python中， `:`  通常用来标记 一个代码块的开始 、 在代码块中的代码 必须产生一个缩进 ~~~**

## 循环

> 循环是用来执行重复任务的一种方式 ~

- while 循环 ： 更善于处理 循环次数不确定的任务
- for 循环 :   更善于 处理 循环次数 确定的任务

### while 循环

```python
while condition:
    pass
else:
    pass
```

condition :  用来定义循环的条件、只有当循环的条件为真的时候， 循环体中的任务才会执行、且任务执行完成后、会继续对 condition进行条件判断、决定是否要继续执行重复的任务 ~~~

### break 和 continue 

break : 强制终止循环
continue: 跳过本次任务、继续下一次重复任务

### else 结构

else 结构中的代码 代表 循环条件不成立的时候，才执行的代码 

循环中的 break 和 else 结构 永远是 互斥的效果 ，循环走 break , 一定不走 else  循环走 else , 一定不走 break 。

### for 循环 

```python
for var in iterable:
    pass
else:
    pass
```

var :   代表 可迭代对象中的 数据 变量 

iterable :  代表 可迭代对象 、常见的可迭代对象有 字符串、列表、元组、集合、字典、 range、 zip、 map、 filter 等对象

**for循环同样支持 continue 和 break 关键字 用来控制循环**
