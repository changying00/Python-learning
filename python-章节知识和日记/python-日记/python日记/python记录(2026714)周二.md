列表的创建的方式

列表list 是一个非常重要的 用来储存多个数据的容器

	存储的数据 是有序 、且 可重复的 

	俩个数据相同的列表，数据一样，但是地址不一样，== is ==对比地址

列表的创建方式

	a) 字面量 定义:使用 中括号 存储多个数据、且多个数据之间使用 逗号分割

	b) list工厂函数：将一个 可迭代的对象 通过 list 函数 转成列表对象

		可迭代对象:字符串、列表、集合、字典、元组、range对象

	c)列表 生成推导式

	[exp for var in iterable [for var in iterable ....] [if condition]]

最外层 的中括号是 列表生产的推导式的语法结构

里面的总括号  代码 括起来的结构 可有可无

对一个可迭代对象 进行遍历 、保留 满足条件的数据、并映射 为指定的数据

如何实现列表的增删改查

--添加数据

 	append(x) : 	向列表的尾部追加数据

	insert(index, x) : 向指定的位置插入数据，(指定的索引前)。

--删除数据

	pop(index-1) = 删除 指定索引位置的元素。如果不传入索引、删除最后一个元素、并返回被删除的元素，索引超出范围，提示错误、、	

	del 关键字删除，该行为 不会返回被删除的元素	

	remove(X)：删除列表中指定的第一个元素，如果要删除的元素 不存在，则抛出错误!!!

--修改数据

	通过索引获取元素，再通过赋值运算更改元素

	ls[0] =  30

--查询数据;

	a) 通过 索引获取元素 ls[0]

	b)根据元素 获取索引 ls.index(x) 、如果 值在列表中 不存在，则 抛出错误！！

列表的遍历方式

 	a)基于索引的遍历

    	列表它的索引范围 0 ~  lenth -1 且支持 索引获取值

 		len(ls)：获取 列表的长度 、python语言中，获取长度、均使用len函数

	b) 基于 值的遍历

	for  val in ls :

		print(val)

	c) 基于索引和值的遍历方式、配合enumerate函数	

	enumerate 枚举函数 它的作用 就是将一个 可迭代对象中的 数据转成元组、且元组中 第一个元素 代表索引值、第二个代表元素。

```
  for index,value in enumerate(ls);
    print(index,value)
```

