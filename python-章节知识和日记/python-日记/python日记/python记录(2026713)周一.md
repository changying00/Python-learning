==while循环 特点:==

    a) 善于处理 循环次数 不确定的任务

	b) 也支持 处理循环次数 确定的任务、通常需要有 循环的三要素

		1.计数器

		2.循环条件

		3.计数器的自增/自减、计数器的改变 会影响的 循环的条件

<br/>

==while 循环的控制: ==

		a)使用计数器控制循环

		b)break 关键字 退出循环

		c)continue 关键字 终止本轮任务、继续下一轮循环任务

<br/>

==range: 生成一个指定数字的序列的对象==

range 函数 有3个使用方式

a) range(n): 生产一个[0,n) 包含 0 但不包含 n 的数字序列对象

b)range(m,n) 生产一个[ m , n)包含m，不包含 n 的数字 序列对象

c)range(m，n，sep = 1):生成一个[m,n)包含m 但不包含n 且步长为 step 的数字序列对象

   如果 m > n,则step 必须< 0 ,否则 step > 0

- `range(101)`：可以用来产生`0`到`100`范围的整数，需要注意的是取不到`101`。
- `range(1, 101)`：可以用来产生`1`到`100`范围的整数，相当于是左闭右开的设定，即`[1, 101)`。
- `range(1, 101, 2)`：可以用来产生`1`到`100`的奇数，其中`2`是步长（跨度），即每次递增的值，`101`取不到。
- `range(100, 0, -2)`：可以用来产生`100`到`1`的偶数，其中`-2`是步长（跨度），即每次递减的值，`0`取不到。
