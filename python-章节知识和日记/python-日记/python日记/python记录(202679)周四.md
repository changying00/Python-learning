M## 位与运算符  &

应用于2个整数的的运算、返回的结果仍旧是整数python位与运算符 & : 相同位 只要有0，则结果为0，否则为1

### 位与运算符的 应用场景:

- 和1 做位与运算、用来判断一个数字是奇数还是偶数
- 判断二进制 指定位 是0还是1( 例子做签到程序，等游戏程序）
- 掩码处理

<br/>

## 位或运算 |

- 位或运算 | : 相同位 只要有1 结果为 1 ，否则为 0 (一真即真)

### 位或的应用场景

- 合并权限

==例子补签==

```python
# 定义一个数字、用来表示当前签到情况
num =12345
print(bin(num))
#判断八号是否签到
n = 8
mash = 2 ** (n - 1)

# 用位或 位与进行 判断和补签
if num & mash == 0:
    print(n,"当天没有签到,正在补签中....")
    num = num | mash
    print(bin(num))
else:
    print(n,"当天已经签到")
```

==例子==

```python
class File:
    # 定义一个类的属性，代表读权限
    READ = 4

    # 定义一个类的属性，代表写权限
    WRITE = 2

    # 定义一个类的属性，代表执行权限
    EXECUTOR = 1

    def __init__(self, path, number):
        self.path = path
        self.number = number

    def can_read(self):
        """判断是否可读"""
        return self.number & self.READ == self.READ

    def can_write(self):
        """判断是否可写"""
        return self.number & self.WRITE == self.WRITE

    def can_execute(self):
        """判断是否可执行"""
        return self.number & self.EXECUTOR == self.EXECUTOR


# 创建一个文件对象，并设置权限：读 + 写 + 执行
file = File(
    "D:/abc/123.py",
    File.READ | File.WRITE | File.EXECUTOR
)

print(file.can_read())
print(file.can_write())
print(file.can_execute())
```

## 异或运算符 ^

- 运算规则：2个数字的二进制相同位 不同则为1、相同为0
- 在异或运算规则中 两个相同的数字 进行异或运算 结果一定是0 、 0 和任意数字A异或运算、结果是这个A

### 异或运算的应用场景

- a) 可以实现2 个数字的交换
- a = a ^ b       ==》 a = c
- b = a ^ b       ==》a = c ^ b 
- a = a ^ b       ==》a = b
- 还可以这样做 a , b = b , a
  
  a = a ^ b   # a ^ b 有第三个数为c ，赋值给a  a = c

b = a ^ b   # 由上a = c 相当于c ^ b => 等于a ，把a 赋值给b  b = a
a = a ^ b   # 现在a = c ，b = a， 可得 c ^ a  = b  ，现在把b的值赋值给a  a=b，实现俩个数字互换

- b） 可以实现简单的 加解密(几乎没啥用)
  - ord(c) : 将指定的字符 转成对应的码点
  - chr(x) : 将一个码点数字 转成对应的字符

"<<" (左移): 将一个数字 通过 二进制 按位 向左移动、低位补0

#### and 语法为 exp1 and exp2

一假即假:

当 exp1 它的结果为加 假的时候， 整个表达式 返回的结果为 exp1 运算结果、此时 exp2 不参与运算(短路现象)

当 exp1 它的结果为加 真的时候， 整个表达式 返回的结果为 exp2 运算结果
