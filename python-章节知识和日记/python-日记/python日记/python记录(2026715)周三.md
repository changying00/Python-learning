列表 中常见的方法

  - append(value) :  向列表的尾部添加数据 value
  - insert(index, value) :  向 指定的 index 索引位置前 添加数据 value
  - pop(index=-1) :  删除 指定索引位置的元素、并返回被删除的元素、 索引越界会产生错误 。 如果不传入索引、默认删除列表中最后一个元素
  - remove(value) :  删除 第一个 value 元素 、 当 value 不存在的时候 会报错 
  - clear()  : 清空 列表 
  - index(value) :  获取 value 元素 在 列表中 第一次 出现的索引位置 、value 不存在， 会报错 。
  - count(value) :  统计 value 元素 在 列表中 出现的次数 
  - reverse()  :  将 列表中的所有元素 进行反转 、该方法 没有返回值 
  - extend(iterable) :  将 可迭代对象中的 数据 合并到 列表中 
  - copy() :  采用 浅克隆 技术 复制 当前 列表 、返回一个 新的 列表

```python
1.算术运算符
  +: 列表 支持 和 另一个列表 做加法运算 、返回一个 合并后的 列表
  
  *: 列表 支持 和一个 正整数 n 做 乘法运算、将列表 的元素重复 n次、返回的结果是一个新列表
2. 关系运算符
  > , >=,< , <= , ==, !=
  
  列表 支持比较大小、比较规则是 追个同位素 进行比较、 知道找到 不相等的数据位置、否则 俩个列表相等
  
3.成员运算符 in, not in
```

```python
切片:  快速对列表中 指定区间的 数据 进行 提取的 一个技术手段 ~~~

语法 : 

    [index] :  获取 列表中 指定 索引位置的元素 、 index 必须 在 规定的范围内 、如果超出范围、会产生错误 

    [start:end] :   快速 提取 [start, end) 区间的 数据 、返回一个 新的列表对象 
        start 如果 不提供 、则 默认值为 0 
        end 如果 不提供 、则 默认值为 列表长度 
        通常需要满足  start < end  、否则 返回一个 空列表 

        在 当前语法中 、满足一个 公式   end - start 等于 截取的长度 ~

    [start:end:step] :  快速 提取 [start, end) 区间的 数据 、且步长为 step 返回一个 新的列表对象 
        step 默认值为 1

        当 step > 0 的时候 、start 如果 不提供 、则 默认值为 0 、 如果 step 小于 0 、则默认 为 -1
        当 step > 0 的时候 end 如果 不提供 、则 默认值为 列表长度 、 如果 step 小于 0 、则默认 为 -length - 1


列表 切片 支持 三个操作 

    1)  使用 切片 提取数据 

    2)  使用 切片 修改数据 

    3)  使用 切片 删除数据 
    
    
    # 克隆一个新的列表 
print(ls[::])

# 快速 反转 列表中的元素 
print(ls[::-1])
```
