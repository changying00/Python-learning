## 身份运算符： is( 是）,  is not (不是)

身份运算符 主要是用来判断  俩个数据在内存中的地址  ==是否相同 == 地址相同的数据是同一个数据、

要获取 某个数据的地址 、可以使用 == id ==函数

** x  is y 等价于 id(x)  == id(y) **

在 python 语言中，不可变类型值相同则 地址 一定相同

==不可变类型: 包含 数字、字符串、布尔值、元组、None ==

==可变类型: 包含 列表 、集合 、 字典 ==

在 python 中 如果 要判断某个值是否是	None ，请使用 is None 进行判断、不要使用 == None(不推荐)

- 比较俩个数据的值是否相同 使用"=="或者"!="
- 判断俩个数据的地址是否相同 、使用is 或者 is not

## 流程控制 - 判断 - 基本使用方式

==单分支条件判断语法:==

```python
语法:
if  condition:
    pass

if: 编写 判断的关键字、代表如果

condition: 用来定义 执行任务的条件

pass: 此时 编写满足条件 执行的任务、pass是一个关键字、在python 中是一个占位符，用来保证语法的完整性
```

== 双分支条件判断 语法:==

```
语法:
if condition:
    pass
else:
    pass
    
    
else: 当 if 条件不成立的时候 会执行的代码
```

==  多分支条件判断 ：==

```python
语法:
if condition:
  pass
elif condition:
  pass
....
else:
  pass

# 获取从键盘输入的成绩
```

## 循环的手段

通过特定的指令、可以将某一段任务 重复执行 直到 条件不满足为止

python	 中实现 循环的手段有俩种

   1) while 循环: 善于处理 循环次数 不确认的任务

```python
while 循环的语法:

while condition:
   pass
 
condition: 循环执行的条件、当满足条件的时候，才会执行重复的任务

pass: 循环体、编写 重复执行的任务代码
在python 语言中 ，while 循环它的完整语法是:
while condition:
  pass
else:
  pass
在 上述 语法中， 当condition条件不成立的时候 会执行 else中的代码
else 结构 和break 永远存在 互斥效果，走break 一定不会执行els，走else一定不走break！！
```

while 循环 处理 循环次数不确定的任务

在循环次数不确定的任务中，可以使用==break == 关键字强制终止循环

2) for 循环: 主要处理 循环次数 确定的任务

主要用来遍历 可迭代的对象

常见的 可迭代的对象包含

	1)range 对象

	2)字符串

	3)列表

	4)元组

	5)集合

	6)字典

语法:
for var in iterable:

	pass

else:

	pass 

-var: 变量名、由开发人员自主命名、代表可迭代对象中的 每一个数据

-iterable：遍历的 可迭代的对象

for 循环 也支持 break 和continue 关键字 来控制循环
