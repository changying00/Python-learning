## 内置函数 (print 和 help）

### print

print(*args, sep=' ', end='\n', file=None, flush=False)

```python
`*args`: 如果一个参数的前面有一个 `*` ,  代表 此时 可以传递 0 ~ N 个参数， 且多个参数之间使用逗号分隔 ，

sep="" 分割符关键字参数 ""里面可以加分隔符，sep=""放在参数的后面，俩个或多个参数分割才会有效果,
设置 打印的多个数据之间的 分隔符 默认是一个空格

end="" 不换行与下一个print输出连接 , end =""

制表符 \t 是水平制表符，相当于键盘 Tab 键，自动空出一段对齐空格（默认占 4/8 个字符宽度，看编辑器设置）
用来排版对齐文字。

\n 换行
```

sep=""是对俩个及以上参数,进行分割可以加\t 俩个输出参数有四个空格，\n参数换行。sep="" 去掉空格，紧贴在一起

<br/>

**  \* 参数 后面的参数 都是关键字参数 、关键字参数 在调用函数的时候，必须提供关键字调用   **

<br/>

## 注释

- 单行注释 ==#== 单独一行最好。
- 多行注释用==**三个双引号 """   """**==或者==**单引号 '''   '''** ==(最好用双引号)，多行注释多用于对模块，函数的解释。
- 字符集编码
  ```python
  # -*- coding: utf-8 -*-
  缩写等于 # coding = utf- 8
  文件编码声明注释，只能出现在文件第 1 行或第 2 行，才能生效，如果#!/usr/bin/python3出现就放在第二行，
  如果没出现，就放在第1行。
  ```
- 特殊注释
  ```python
  #!/usr/bin/python3 放在代码第一行
   该注释往往作为模块的第一行代码，该行注释 是为了让 Linux 操作系统(在linux里面运行脚本）
   能够快速找到 python解析器的指令 
  ```
