### 集合中没有重复的元素

集合中不能包含集合，因为集合本身也是可变类型，所以集合不能作为集合的元素，我们可以创建出列表含列表，但不能创建出集合的集合。

```python
1.算术运算符：
  - : 计算俩个集合的差集

  & : 计算 2个集合的 交集
  
  | : 计算 2个集合的 并集
  
  ^ : 计算 2个集合的 补集
3. 关系运算符
  >, >= , < ,<= , ==, !=

4. 成员运算符
  in / not in
```

### 字典

字典：是一个用来存储多个值的容器、它的每一个数据 由建和值 俩个部分组成

在编程中、字典 通常 可以用来描述 一个对象的信息、例如 某个人（姓名、年龄、性别）

字典 底层采用 散列表+链表 结构 进行数据的存储

字典健的特点: 不可重复、且 键 必须 可hash的、只能是 不可变类型、例如 数字 、字符串、bool、元组、None

```python
1.字面量
2.dict 工厂函数
  a) 支持 传入一个二维 可迭代的对象、且可迭代对象中 可迭代对象的长度 必须是2
    [[1,2][3,4],[5,6]]
  b) 支持 传入 关键字参数、 直接转成字典
    dct5 = dict(a = 1,b = 2, c= 3)
  c) 可以将 字典 转成字典
    dct6 = dict(**dct4,**dct5)
    print(dct6)
3.字典生成推导式
  语法{ exp1:exp2 for var in iterable [for var in iterable ...][if condition]}
4.静态方法 fromkeys
  
  dict.fromkeys(iterable,fillvalue = None)
  将可迭代对象中的数据 作为键，并给键填充值位 fillvalue
  



```

### 字典的 基本操作

```python

  a)添加数据
    setdefault(key,default):当键不存在的时候,才会向字典中添加数据
  
  b)修改数据
  
  c)删除数据
    pop(key,default = None):根据 键删除 数据、并返回 键对应的值，如果不存在，返回default设置的值
    
    popitem():删除字典中 最后一个 键值对、并返回一个键和值组成的二元组(不常用)
    
    clear():清空 整个字典，返回None
    
    del person['age'] 删除对应字典中键和值，
  d) 查询数据
    dct[key]: 根据键获取值、键不存在、会抛出错误
    
    get(key,default= None):获取指定的键的值，如果键不存在，则返回default设置的值,默认值为None
  

```

### 字典常见的方法

```python
合并 2个 字典 ,**dct 展开 字典 、并将 字典中数据转成关键字 
此时 要展开的 字典 它的键 必须 全部是 字符串 
dct3 = dict(**dct, **dct2)
print(dct3)



```

#### sort()：自己排（修改原列表）

#### sorted()：复制一份再排（返回新列表）

#### reverser 默认升序，reverse = True 是降序 ,reverse = False 是升序

|区别|`sort()`|`sorted()`|
|--|--|--|
|作用对象|列表(list)|任何可迭代对象|
|是否修改原数据|✅ 修改|❌ 不修改|
|返回值|`None`|返回新列表|
