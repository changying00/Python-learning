## Python 进制转换总结

### 一、十进制转换其他进制

Python 提供三个函数：

|函数|作用|返回类型|
|--|--|--|
|`bin(x)`|十进制转二进制|字符串 `str`|
|`oct(x)`|十进制转八进制|字符串 `str`|
|`hex(x)`|十进制转十六进制|字符串 `str`|

注意：

- `bin()` 返回结果以 `0b` 开头
- `oct()` 返回结果以 `0o` 开头
- `hex()` 返回结果以 `0x` 开头

---

### 二、十进制转换其他进制原理

### 除基取余法（短除法）

将十进制转换为其他进制：

- 二进制：除以 2
- 八进制：除以 8
- 十六进制：除以 16

步骤：

1. 不断除以目标进制的基数
2. 记录每次余数
3. 余数从下往上排列

---

### 三、其他进制转换十进制

使用：

```python
int(str, base)
```

参数：

- `str`：需要转换的进制字符串
- `base`：原数字的进制

常用：

```python
int("1010", 2)    # 二进制转十进制
int("12", 8)      # 八进制转十进制
int("A", 16)      # 十六进制转十进制
```

---

### 四、进制转换总结

|转换方向|方法|
|--|--|
|十进制 → 二进制|`bin()`|
|十进制 → 八进制|`oct()`|
|十进制 → 十六进制|`hex()`|
|二进制 → 十进制|`int(x, 2)`|
|八进制 → 十进制|`int(x, 8)`|
|十六进制 → 十进制|`int(x, 16)`|

---

### 五、Python中的进制表示

|前缀|进制|
|--|--|
|`0b`|二进制|
|`0o`|八进制|
|`0x`|十六进制|

---

### 六、核心记忆

- 十进制转其他进制：**除基取余**
- 其他进制转十进制：**幂次方求和**
- `bin()`、`oct()`、`hex()` 返回的是字符串

---

### 七 16进制核心记忆

- `0x` 表示十六进制
- 十六进制范围：`0~9`、`A~F`
- `A~F` 表示十进制 `10~15`
- 十六进制转十进制：按 16 的幂次展开求和
- 十进制转十六进制：除 16 取余
- 十六进制满 16 进一

## python 字节大小

- 二进制是由 0 、1 组成的数字、二进制中的每一个数字 都代表 1 bit(位)
  
  1B(字节） = 8bit
  
  计算机在进行二进制存储的时候，最高位，位符号位，0代表整数、1代表负数
  
  1个字节表示的最大数字是多少？ 最小数字是多少？
  
  1个字节的最大数字 二进制位== 0111 1111==、最小数字的二进制是 ==1000 0000==
  
  1个字节下的==0111 1111 ==十进制是 2^7 -1 = 127
  
  1个字节下的 1000 0000 (原码) 它的十进制 必须先计算对应的补码
  
     补码 = 正数原码取反后 + 1 == 0111 1111 + 1       == ==1000 0000(补码)==     ==>  -128
  
   负数补码 = 对应正数绝对值的原码取反 + 1
  
   2个字节的最大数字是 32767(2^15 -1)  最小数字是 -32768
  
   4个字节的最大数字是 2^31 -1 (大约21亿) 、最小数字是 -2^31
  
   8个字节的最大数字是 2^63 -1
