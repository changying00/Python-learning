## 二、总策略（一句话）

**主线就业：爬虫 / RPA / 业务自动化；副线加分：AI 应用落地（API + 简单 RAG）。**

- 不要主冲算法岗、不要空学模型理论。
- 学长路径（爬虫/RPA/数据）= 就业主线；班上 AI = 简历差异化。
- 简历形态：2 个业务项目（爬虫 + RPA）+ 1 个可演示 AI 小项目。

### 岗位投递优先级

1. **Python 爬虫 / 数据采集**（需求相对稳）
2. **RPA / 流程自动化**（影刀、Python 自动化，二线好进）
3. **Python 开发 / 脚本开发**（业务系统、接口、工具）
4. **数据分析助理 / 数据开发初级**（SQL + pandas）
5. **AI 应用 / 智能客服助理**（加分项，数量少，不作为唯一主投）

> 原则：主投 1–3；AI 写在技能与项目里拉开差距，而不是只投「算法工程师」。

## 三、技术栈分层

### A 层：必会（没有这些很难过一面）

| 类别 | 技术 | 学到什么程度 |
|------|------|----------------|
| 语言 | Python 3 | 语法、OOP、异常、模块、装饰器、生成器、迭代器、`*args/**kwargs`、上下文管理器 |
| 数据结构 | list/dict/set、常用思想 | 去重、排序思路、哈希查找；链表/栈队列概念 |
| 网络 | HTTP | GET/POST、状态码、Header、Cookie、Session、JSON |
| 爬虫 | `requests` + BeautifulSoup / lxml | 静态页、分页、详情、解析清洗 |
| 正则 | `re` | 手机号、邮箱、价格、标签内文本 |
| 存储 | MySQL + SQL | 建表、CRUD、WHERE、ORDER、GROUP、简单 JOIN、索引概念 |
| 连库 | `pymysql` 或 SQLAlchemy 入门 | 爬取结果写入数据库 |
| 文件 | CSV / JSON / 读写 | 落地、备份、简单报表 |
| 工具 | Git | clone、add、commit、push、分支概念 |
| 环境 | venv / pip | 虚拟环境、`requirements.txt` |

### B 层：主岗位加分（爬虫 / RPA 高频）

| 类别 | 技术 | 学到什么程度 |
|------|------|----------------|
| 动态页 | Playwright **或** Selenium（推荐 Playwright） | 打开页、等待、点击、填表、取 HTML/下载 |
| 反爬常识 | UA、延迟、代理概念、验证码类型 | 能讲思路，不要求破解一切 |
| 调度 | APScheduler 或系统定时任务 | 定时跑爬虫/脚本 |
| 日志 | `logging` | 分级、失败可追溯 |
| RPA | 影刀 **或** UiPath 入门 + Python | 完成「登录→下载→整理」类流程 |
| Excel | `openpyxl` / pandas 入门 | 读写表格、简单汇总 |
| 并发入门 | 多线程 / 线程池概念 | 何时用、GIL 是什么 |

### C 层：AI 差异化（简历亮点，不主投算法）

## 八、三个项目规格（写进简历的目标形态）

### 项目 B（双保险）：RPA / 办公自动化

- 影刀/键鼠网页自动化 **或** Python（Playwright/selenium）+ openpyxl

- **技术点：** 自动化工具、Excel、文件整理、等待重试
