# 关于作者（About the Author）

> **原书**：《Learning Python》（6th Edition），作者 Mark Lutz

---

## 作者简介（About the Author）

### 英文原文

> Mark Lutz is the author of Python's classic and foundational texts, a former trainer with two decades of experience teaching Python to newcomers, and one of the people responsible for the prominence that Python enjoys today.
> Mark wrote the three O'Reilly books *Learning Python*, *Programming Python*, and *Python Pocket Reference*, all currently in fourth, fifth, or sixth editions. He has been using and promoting Python since 1992, started writing Python books in 1995, and began teaching Python classes in 1997.
> All told, Mark has taught thousands of learners live and in person, and his published works span 12k pages among 15 books that cover Pythons 1.X through 3.X. He also has BS and MS degrees in computer science, work experience in compilers and other domains, and a current interest in Python-coded apps that run on both PCs and phones.
> For more author background, see Mark's books-and-software website, `learning-python.com`.

### 中文翻译

> **Mark Lutz** 是 Python 经典与奠基之作的作者，曾是一名拥有二十年向新手教授 Python 经验的讲师，也是让 Python 拥有当今地位的关键人物之一。
> Mark 撰写了三本 O'Reilly 图书：《Learning Python》（Python 学习手册）、《Programming Python》（Python 编程）与《Python Pocket Reference》（Python 袖珍参考），目前均已出到第四、第五或第六版。他从 1992 年开始使用并推广 Python，1995 年开始撰写 Python 图书，1997 年开始教授 Python 课程。
> 总而言之，Mark 亲自面对面教过数千名学习者，其出版物累计 15 本书、约 12,000 页，覆盖 Python 1.X 到 3.X 的全部版本。他拥有计算机科学学士与硕士学位，有过编译器等领域的工作经验，目前对同时运行在 PC 与手机上的 Python 应用很感兴趣。
> 更多作者背景，见他的图书与软件网站 `learning-python.com`。

### 深度理解

- **核心概念**：本书作者 Mark Lutz 是 Python 教学领域的"元老级"人物，其深耕 Python 三十年的背景，是本书内容扎实、讲解细密的重要来源。
- **底层视角**：一家"书龄"横跨 Python 1.X 到 3.X 的作者，意味着他对语言近三十年的演进（从经典式类到新式类、从 Unicode 到类型提示）有亲历者的理解，这也是本书第 41 章讨论"变化速率"时的底气所在。
- **设计原因**：作者特意列出教学人数与出版篇幅，是在强调"这本书不只讲语法，更是作者二十年教学经验的沉淀"。
- **初学者误区**：不要因为作者毕业于计算机专业与编译器领域，就以为本书只写给高手——恰恰相反，本书面对的正是刚入门的初学者。
- **延伸了解**：还想知道更多？可访问 `learning-python.com` 查阅作者的图书清单与软件项目。

## 版权页（Colophon）

### 英文原文

> The animal on the cover of *Learning Python*, sixth edition, is a wood rat (*Neotoma muridae*). The wood rat lives in a wide range of conditions (mostly rocky, scrub, and desert areas) over much of North and Central America, generally at some distance from humans. Wood rats are good climbers, nesting in trees or bushes up to six meters off the ground; some species burrow underground or in rock crevices, or inhabit other species' abandoned holes.
>
> These grayish-beige, medium-size rodents are the original pack rats: the carry anything and everything into their homes, whether or not it's needed, and are especially attracted to shiny objects such as tin cans, glass, and silverware.
> The cover illustration is by Karen Montgomery, based on a 19th-century engraving from *Cuvier's Animals*. The series design is by Edie Freedman, Ellie Volckhausen, and Karen Montgomery. The cover fonts are Gilroy Semibold and Guardian Sans. The text font is Adobe Minion Pro; the heading font is Adobe Myriad Condensed; and the code font is Dalton Maag's Ubuntu Mono.

### 中文翻译

> 《Learning Python》第六版封面上的动物是木鼠（*Neotoma muridae*）。木鼠生活在北美与拉丁美洲大半个地区各种环境下（多在山石、灌丛和沙漠地带），它们普遍远离人居。木鼠的爬树本领高超，能在地面六米以上的树枝或灌木丛筑巢；有些种类会在地下掏洞、在岩缝间挖穴，或栖居在别的动物遗弃的洞里。这些灰棕色的中型鼠类是最原始的"囤积鼠"（pack rats）：无论有用没用，它们都会把各种东西搬回窝里，尤其对锡罐、玻璃、银器等闪闪发光的东西毫无抵抗力。O'Reilly 封面上的许多动物都处于濒危状态，而且所有这些动物对世界都很重要。
> 封面插画由 Karen Montgomery 绘制，依据 19 世纪的铜版画《Cuvier's Animals》（居维叶的动物图谱）创作。系列封面设计由 Edie Freedman、Ellie Volckhausen 与 Karen Montgomery 负责。封面字体为 Gilroy Semibold 与 Guardian Sans；正文字体为 Adobe Minion Pro，标题字体为 Adobe Myriad Condensed，代码字体为 Dalton Maag 的 Ubuntu Mono。

### 深度理解

- **核心概念**：版权页介绍封面的"木鼠"（wood rat）——它既是版本装帧的趣味元素，也隐喻 Python 的"囤积特性"（语言本身也在不断吸收各种新特性）。
- **关联理解**：结合第 41 章所说的"Python 海啸"，木鼠"囤积闪亮物件"的习性，正是对 Python 语言持续不断地吸收特性（类型标注、match 语法、异常组等）的绝佳隐喻。
- **读者建议**：这是全书的收尾彩蛋，可轻松一读；想更深入了解封面设计背后的 19 世纪动物图谱，可自行搜索 *Cuvier's Animals*。
