五、8 月（现在 → 8.31）语法收尾 + 能爬静态页
================================================================================
阶段目标：类不再卡；文件/异常/模块/正则过关；requests 小爬虫 ×2

【第 1 周 · 类与 OOP 收尾】（你当前周）
  学：类/对象、__init__/self、实例与类属性、继承与 super、__str__
  做：
    - SpiderTask 类：url、status、fetch()、parse()（parse 可先假数据）
    - DataItem 类：字段 + to_dict()
  验收：不看教程能默写一个带继承的小例子；不学元类/描述符
  就业关联：后面 Scrapy 的 Item、自定义类、中间件都建立在 OOP 上

【第 2 周 · 文件 / 异常 / 模块 / 环境】
  学：with open、json/csv、try/except、import 与包、venv、pip、requirements.txt
  做：上周类输出改存 json/csv；建 utils/io_utils.py、log_utils.py
  验收：换一台思路——别人按 requirements 能装依赖跑你的脚本

【第 3 周 · 正则 + 字符串】
  学：re 的 search/findall/sub；贪婪非贪婪；价格/链接/中文模式
  做：HTML 片段抽标题链接价格；price_clean("¥12.5") / "12元" → float
  验收：10 个脏价格字符串清洗全对；就业关联：清洗与简单解析面试常问

【第 4 周 · HTTP + requests】
  学：方法/状态码/Header/Cookie 概念；requests get/post/headers/params/session/timeout
  做（本月必交）：
    小项目 A：列表页 → 标题+链接+时间 → CSV
    小项目 B：公开数据页 → JSON
  验收标准：
    - 分函数或类，有超时与异常处理
    - 换页或换 URL 参数能跑
    - README 三句话说明怎么运行
  加分：用 session 保持 Cookie；打印耗时

【8 月末日检查】全过再进 9 月，缺项第一周补
  [ ] OOP 默写小例子
